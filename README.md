# 💀 Чёрный Вестник

Telegram-бот для ежедневных сатирических дайджестов групповых обсуждений. Никаких Android-приложений и APK.

Стек: Telegram Bot API + Cloudflare Workers/D1 + Groq (Qwen). Цель: бесплатное использование в рамках лимитов тарифов.

**Статус:** репозиторий инициализирован. До полноценного запуска необходимо загрузить исходники, выполнить миграции, задать секреты Cloudflare и зарегистрировать Telegram webhook. Не считайте репозиторий работающим ботом до сквозного теста.

Используйте `/enable`, `/time`, `/now`, `/status`, `/forgetme`, `/optin`, `/disable`, `/wipe` после развёртывания и подключения webhook.

История чата перед добавлением бота недоступна. Участников нужно предупредить о сборе сообщений и передаче выборки внешнему AI-провайдеру.
